## Quizify

**Quizify** is an application that helps you quickly review what you have studied by creating quizzes

The application is developed using **C# and .NET 8.0** with **SQL Server** as the database engine. Provides an elegant, eye-friendly, and user-friendly interface with smooth animations

---

## Features
- Adding and modifying courses
- Create and edit lessons
- Create and edit questions
- Create quizzes with options for the number of questions and time per question to make things more challenging
- The ability to evaluate answers after completing them
- The ability to see the final result after completing the exam and correcting the questions
- An interactive, elegant, and eye-friendly interface to make using the app more enjoyable
